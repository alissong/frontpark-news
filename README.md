
# frontpark-news

Uma página simples para servir como newsletter, desenvolvida com React e Vite.

## Descrição

Este projeto tem como objetivo fornecer uma página web moderna para divulgação de novidades, comunicados ou informações relevantes, funcionando como uma newsletter digital.

## Estrutura do Projeto


```text
src/
	App.jsx                # Componente principal da aplicação
	App.css                # Estilos globais
	frontpark_newsletter.jsx # Componente da newsletter
	index.css              # Estilos base
	main.jsx               # Ponto de entrada da aplicação
	assets/                # Imagens e outros arquivos estáticos
		hero.png
		react.svg
		vite.svg
```

## Tecnologias Utilizadas

- React
- Vite
- JavaScript
- CSS

## Como instalar e rodar localmente


1. Clone este repositório:

```bash
git clone <repo-url>
cd frontpark-news/frontpark-news
```

2. Instale as dependências:

```bash
npm install
```

3. Rode o projeto em modo desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível em `http://localhost:5173` (ou porta definida pelo Vite).
